# 🗺️ Hoja de Ruta: Integración SIFEN (Vía Sifende)

Este documento detalla los pasos técnicos y operativos necesarios para alinear el sistema **Solver** con los requerimientos de la Facturación Electrónica en Paraguay, utilizando la infraestructura de **Sifende**.

## Fase 1: Cimientos y Cumplimiento Legal
- [ ] **Certificado Digital:** Adquisición del archivo de firma (.p12) ante una entidad certificadora autorizada.
- [ ] **Habilitación en SET:** Trámite de registro en el Sistema E-kuatia para operar como facturador electrónico.
- [ ] **Entorno de Pruebas:** Configuración de credenciales de API (Sandbox) y pruebas de conectividad con los endpoints de Sifende.

## Fase 2: Adaptación de la Base de Datos
- [ ] **Extensión de Cabecera (`pos_ventas_cabecera`):**
    - `cdc`: Almacenamiento del Código de Control (44 dígitos).
    - `qr_url`: Enlace para la representación gráfica (KUDE).
    - `sifen_status`: Estados (Aprobado, Rechazado, Contingencia).
    - `xml_path`: Referencia al archivo XML firmado y aprobado.
- [ ] **Detalle de Venta (`pos_ventas_detalle`):**
    - Desglose de base imponible por tipo de IVA (10%, 5%, Exenta) de forma individual por ítem para cumplir con el esquema XML de SIFEN.

## Fase 3: Lógica de Negocio e Impuestos
- [ ] **Motor de Cálculo SIFEN:** Refactorizar el método `finalizeSale` en `Order.php` para asegurar redondeos conformes a la normativa técnica de la SET.
- [ ] **Validación de Receptor:** Integrar el endpoint de Sifende para consulta de RUC, asegurando que los datos de facturación sean válidos antes de procesar la venta.

## Fase 4: Desarrollo del Integrador (API Client)
- [ ] **Servicio Sifende:** Crear `SifendeService.php` en la carpeta `models` o `services` para gestionar:
    - Autenticación y renovación de tokens.
    - Mapeo de objetos `Order` a formato JSON/XML de Sifende.
    - Recepción de respuestas y gestión de códigos de error de la SET.

## Fase 5: Interfaz del Punto de Venta (UX)
- [ ] **Actualización de Tickets (KUDE):** Rediseñar el ticket de 80mm para incluir obligatoriamente el **Código QR** y el CDC.
- [ ] **Gestión de Errores en Tiempo Real:** Alertar al cajero si una factura es rechazada por la SET para su corrección inmediata (ej: RUC mal cargado).

## Fase 6: Contingencia y Auditoría
- [ ] **Modo Contingencia:** Lógica para emitir facturas offline firmadas digitalmente cuando no hay conexión, permitiendo la impresión inmediata.
- [ ] **Sincronización Diferida:** Módulo de transmisión automática para facturas en contingencia dentro del plazo legal de 72 horas.
- [ ] **Reportes Fiscales:** Vista de conciliación entre ventas internas y facturas aprobadas por la SET.
